Política de Privacidade

Gargaloop Publicador · última atualização: 14/11/2026
InícioEnglish versionTermos de uso

O Gargaloop Publicador é uma ferramenta interna do projeto Gargaloop. Ela envia os vídeos de humor aprovados pelo próprio projeto às contas do projeto no YouTube, no Instagram e no TikTok, sempre depois de aprovação manual.

  • YouTube: usa os Serviços de API do YouTube para enviar vídeos aos canais do projeto e ler as estatísticas desses canais. Ao usar a ferramenta, você concorda com os Termos de Serviço do YouTube. O tratamento de dados pelo Google é regido pela Política de Privacidade do Google.
  • Instagram: usa a API do Instagram (Meta) para publicar reels na conta profissional do projeto. O tratamento de dados pela Meta é regido pela Política de Privacidade do Instagram.
  • TikTok: usa o Login Kit e a Content Posting API do TikTok para enviar vídeos à conta do projeto como rascunho; a publicação final é feita manualmente no aplicativo do TikTok. O tratamento de dados pelo TikTok é regido pela Política de Privacidade do TikTok.

Quais dados acessamos

  • Dados básicos da conta ou canal autorizado: ID, nome, @ e foto de perfil (no TikTok, pelo escopo user.info.basic).
  • Os vídeos que nós mesmos enviamos, com título, legenda, descrição, tags e configurações de privacidade (no TikTok, pelo escopo video.upload).
  • Estatísticas dos nossos vídeos e canais (visualizações, retenção, inscritos), pela API do YouTube Analytics.

Não acessamos dados de espectadores ou seguidores, comentários de terceiros, mensagens diretas nem contas que não sejam do projeto.

Como usamos

Só para publicar os nossos próprios vídeos e acompanhar o desempenho deles. Não usamos os dados para publicidade, criação de perfis nem qualquer outra finalidade.

Armazenamento e compartilhamento

  • Os tokens de acesso (Google, Meta e TikTok) ficam só no computador do projeto, guardados no Keychain do macOS (armazenamento criptografado do sistema).
  • As estatísticas são registradas numa planilha local do projeto, sem servidor externo.
  • Não vendemos, não compartilhamos e não transferimos esses dados a terceiros.

Retenção e exclusão

As estatísticas ficam guardadas enquanto o projeto estiver ativo e são atualizadas a cada 30 dias, no máximo, como pedem as políticas da API do YouTube. Para revogar o acesso da ferramenta a qualquer momento, acesse as configurações de segurança da Conta Google. No Instagram, o acesso pode ser removido em Apps e sites; no TikTok, em Configurações e privacidade › Segurança e permissões › Permissões de apps. Os dados armazenados localmente são apagados em até 7 dias após a revogação ou mediante pedido pelo e-mail abaixo.

Cookies

Este site e a ferramenta não usam cookies nem rastreadores.

Privacy Policy

Gargaloop Publicador · last updated: November 14, 2026

Gargaloop Publicador is an internal tool of the Gargaloop project. It sends the project's own approved comedy videos to the project's own YouTube, Instagram and TikTok accounts, always after manual approval.

  • YouTube: uses the YouTube API Services to upload videos to the project's channels and read those channels' statistics. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.
  • Instagram: uses the Instagram API (Meta) to publish reels to the project's professional account. Meta's handling of data is described in the Instagram Privacy Policy.
  • TikTok: uses TikTok Login Kit and the Content Posting API to send videos to the project's account as drafts; final posting is done manually in the TikTok app. TikTok's handling of data is described in the TikTok Privacy Policy.

Data we access

  • Basic data of the authorized account or channel: ID, name, handle and profile picture (on TikTok, via the user.info.basic scope).
  • Videos we upload ourselves, with their title, caption, description, tags and privacy settings (on TikTok, via the video.upload scope).
  • Statistics for our own videos and channels (views, retention, subscribers) through the YouTube Analytics API.

We do not access viewer or follower data, third-party comments, direct messages or any account that does not belong to the project.

How we use it

Only to publish our own videos and track their performance. We do not use the data for advertising, profiling or any other purpose.

Storage and sharing

  • Access tokens (Google, Meta and TikTok) are stored only on the project's computer, in the macOS Keychain (the system's encrypted storage).
  • Statistics are recorded in a local project spreadsheet, with no external server.
  • We do not sell, share or transfer this data to any third party.

Retention and deletion

Statistics are kept while the project is active and refreshed at least every 30 days, as the YouTube API policies require. You can revoke the tool's access at any time through Google Account security settings. On Instagram, access can be removed under Apps and websites; on TikTok, under Settings and privacy › Security and permissions › App permissions. Locally stored data is deleted within 7 days of revocation, or on request by email.

Cookies

This site and the tool do not use cookies or trackers.
