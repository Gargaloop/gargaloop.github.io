Gargaloop Publicador · última atualização: 10/11/2026
InícioEnglish versionTermos de uso

O Gargaloop Publicador é uma ferramenta interna do projeto Gargaloop. Ela usa os Serviços de API do YouTube para enviar vídeos aos canais do próprio projeto e ler as estatísticas desses canais. Ao usar a ferramenta, você concorda com os Termos de Serviço do YouTube. O tratamento de dados pelo Google é regido pela Política de Privacidade do Google.

Quais dados acessamos

  • Dados básicos do canal autorizado: ID, nome e @.
  • Os vídeos que nós mesmos enviamos, com título, descrição, tags e configurações de privacidade.
  • Estatísticas dos nossos vídeos e canais (visualizações, retenção, inscritos), pela API do YouTube Analytics.

Não acessamos dados de espectadores, comentários de terceiros nem canais que não sejam do projeto.

Como usamos

Só para publicar os nossos próprios vídeos e acompanhar o desempenho deles. Não usamos os dados para publicidade, criação de perfis nem qualquer outra finalidade.

Armazenamento e compartilhamento

  • Os tokens de acesso ficam só no computador do projeto, guardados no Keychain do macOS (armazenamento criptografado do sistema).
  • As estatísticas são registradas numa planilha local do projeto, sem servidor externo.
  • Não vendemos, não compartilhamos e não transferimos esses dados a terceiros.

Retenção e exclusão

As estatísticas ficam guardadas enquanto o projeto estiver ativo e são atualizadas a cada 30 dias, no máximo, como pedem as políticas da API do YouTube. Para revogar o acesso da ferramenta a qualquer momento, acesse as configurações de segurança da Conta Google. Os dados armazenados localmente são apagados em até 7 dias após a revogação ou mediante pedido pelo e-mail abaixo.

Cookies

Este site e a ferramenta não usam cookies nem rastreadores.

Privacy Policy

Gargaloop Publicador · last updated: November 10, 2026

Gargaloop Publicador is an internal tool of the Gargaloop project. It uses the YouTube API Services to upload videos to the project's own channels and to read those channels' statistics. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Data we access

  • Basic data of the authorized channel: ID, title and handle.
  • Videos we upload ourselves, with their title, description, tags and privacy settings.
  • Statistics for our own videos and channels (views, retention, subscribers) through the YouTube Analytics API.

We do not access viewer data, third-party comments or any channel that does not belong to the project.

How we use it

Only to publish our own videos and track their performance. We do not use the data for advertising, profiling or any other purpose.

Storage and sharing

  • Access tokens are stored only on the project's computer, in the macOS Keychain (the system's encrypted storage).
  • Statistics are recorded in a local project spreadsheet, with no external server.
  • We do not sell, share or transfer this data to any third party.

Retention and deletion

Statistics are kept while the project is active and refreshed at least every 30 days, as the YouTube API policies require. You can revoke the tool's access at any time through Google Account security settings. Locally stored data is deleted within 7 days of revocation, or on request by email.

Cookies

This site and the tool do not use cookies or trackers.
